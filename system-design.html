Agentic System 的系统设计平面

LLM Multi-Agent System Design

这一部分研究的不是怎样更新一个 LLM 的权重，而是怎样把多个 Agent、工具与环境组织成有效系统：选谁、怎样连接、何时执行、传什么、如何融合，以及运行时是否应改变结构。网页以 25 篇正式论文为核心，并把 workshop 与预印本前沿单独标注。
